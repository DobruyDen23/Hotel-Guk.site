# Готель «Гук» — сайт (HTML + CSS)

Відкрийте `index.html` у браузері. Нічого збирати не треба.

## Структура

```
guk-site/
├── index.html          — головна сторінка, українська (блоки пронумеровані)
├── en/index.html       — англійська версія (генерується, див. нижче)
├── tools/make_en.py    — скрипт, що створює англійську версію
├── css/
│   ├── fonts.css       — підключення шрифтів Literata і Manrope
│   ├── variables.css   — УСІ кольори, шрифти, відступи (міняти тут)
│   ├── base.css        — скидання стилів, типографіка, контейнер
│   ├── components.css  — кнопки, мітки, заголовки секцій, посилання
│   ├── header.css      — 00. шапка + мобільне меню
│   ├── home.css        — 01–13. секції головної
│   └── footer.css      — 14. футер
├── js/main.js          — шапка при прокрутці, мобільне меню, рік у футері
├── fonts/              — файли шрифтів (кирилиця + латиниця)
└── images/             — фото (тимчасові, з поточного сайту)
```

## Як знайти код блоку

Кожен блок в `index.html` має коментар із номером і назвою, наприклад
`04. НОМЕРИ`. У `css/home.css` той самий номер і назва — шукайте їх
через Ctrl+F.

| №  | Блок                | HTML-клас      |
|----|---------------------|----------------|
| 00 | Шапка + меню        | `.header`, `.menu` |
| 01 | Головний екран      | `.hero`        |
| 02 | Бігучий рядок       | `.ticker`      |
| 03 | Про готель + цифри  | `.about`, `.stats` |
| 04 | Номери              | `.rooms`, `.room-card` |
| 05 | Відпочинок (плитки) | `.rest`, `.tile` |
| 06 | Що входить          | `.included`    |
| 07 | Ресторан            | `.restaurant`  |
| 08 | Сезони              | `.seasons`     |
| 09 | Пакети              | `.packages`    |
| 10 | Відгуки (вимкнено)  | `.reviews`     |
| 11 | Розташування        | `.location`    |
| 12 | Часті питання       | `.faq`         |
| 13 | Фінальний заклик    | `.cta`         |
| 14 | Футер               | `.footer`      |

Назви класів побудовані за схемою BEM: `.блок__елемент--варіант`
(наприклад `.room-card__price`, `.btn--dark`).

## Фото

Зараз стоять тимчасові фото з Unsplash (безкоштовна ліцензія), вони
вантажаться за посиланням `https://images.unsplash.com/...`.
Власні фото кладіть у `images/` і міняйте `src` на `images/назва.jpg`.
Перед запуском сайту краще замінити всі стокові фото на справжні.

## Анімації

- `.reveal` — елемент плавно з'являється при прокрутці.
- `.reveal--image` — фото «відкривається» шторкою.
- `data-parallax` — фото рухається повільніше за сторінку.
- Якщо в системі вимкнені анімації — сайт показує все без руху.
- Логіка — `js/main.js` (пункти 5–9), стилі — `components.css`.

## Англійська версія

- Лежить у `en/index.html`, перемикач UA / EN — у шапці
  (на телефоні — у меню).
- Генерується автоматично з української сторінки:
  `python3 tools/make_en.py`
- Змінили текст українською → додайте переклад у словник `T`
  у `tools/make_en.py` і запустіть скрипт. Руками `en/index.html`
  не редагуйте — зміни перезапишуться.

## Темна тема

- Кольори темної теми — у `css/variables.css`, блок `:root[data-theme="dark"]`.
- Кнопка ☾/☀ у шапці перемикає тему (логіка — `js/main.js`, пункт 4).
- Вибір зберігається в браузері. Якщо гість нічого не обирав —
  сайт бере тему з налаштувань його системи.
- Нові кольори додавайте як змінні, а не прямо в стилі,
  інакше вони не зміняться в темній темі.
