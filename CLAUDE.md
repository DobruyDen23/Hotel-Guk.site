# CLAUDE.md — сайт готелю GUK

Правила для Claude (і для людей) при роботі з цим репозиторієм.
Відповідай користувачу українською.

## Проєкт

Сайт готелю **GUK** (Поляниця, біля Буковеля, Карпати).
Чистий **HTML + CSS + JavaScript**, без фреймворків і без збірки.
Відкривається напряму: `index.html` (українська) і `en/index.html` (англійська).
Публікується через GitHub Pages з гілки `main`.

## Робочий процес (git)

1. **Спочатку завжди забирай свіжі зміни** — власник редагує сайт сам у VS Code:
   `git fetch origin main` і працюй від `origin/main`.
2. Свої зміни роби **в окремій гілці** (`claude/коротка-назва`) і пропонуй
   через pull request. Напряму в `main` не комітимо, якщо власник прямо не попросив.
3. Повідомлення комітів — українською, коротко про суть змін.
4. Ніколи не перезаписуй файли власника старішою версією з архіву чи пам'яті.
   Якщо отримав zip — порівняй (`diff`) і перенеси лише реальні зміни.

## Структура

```
index.html          — головна, українська. Блоки пронумеровані коментарями
en/index.html       — англійська версія. ГЕНЕРУЄТЬСЯ, руками не редагувати
tools/make_en.py    — генератор англійської версії (словник перекладів T)
css/
  variables.css     — УСІ кольори, шрифти, відступи + темна тема
  fonts.css         — локальні шрифти Literata (заголовки) і Manrope (текст)
  base.css          — скидання, типографіка, .container, .section
  components.css    — кнопки, мітки, заголовки секцій, анімації .reveal
  header.css        — шапка, мобільне меню, перемикачі мови й теми
  home.css          — секції головної (номери блоків як в index.html)
  footer.css        — футер
js/main.js          — уся інтерактивність, пункти пронумеровані
fonts/, images/
```

## Правила коду

- **Коментарі — українською.** Кожен блок у HTML починається з коментаря
  `<!-- ==== 04. НОМЕРИ ... ==== -->`, у CSS — такий самий номер і назва.
  Новий блок — новий номер, і він же в обох файлах.
- **Класи за BEM:** `.блок__елемент--варіант` (`.room__price`, `.btn--dark`).
- **Кольори лише через змінні** з `variables.css`. Жодних кольорів напряму
  в стилях — інакше вони не зміняться в темній темі. Новий колір →
  нова змінна і для `:root`, і для `:root[data-theme="dark"]`.
- Виняток: `--color-cream` і `--color-graphite` — фіксовані кольори для
  кнопок і тексту поверх фото, однакові в обох темах.
- Адаптивні правила — в кінці кожного блоку CSS. Перевіряй ширини
  1440, 1024, 768, 390 і 360 px: текст не має вилазити за край.
- Анімації: клас `.reveal` (поява), `.reveal--image` (шторка для фото),
  `data-parallax`. Обов'язково поважати `prefers-reduced-motion`.
- Доступність: `alt` для фото, `aria-label` для кнопок-іконок,
  фокус з клавіатури має працювати.

## Англійська версія

- Після **будь-якої** зміни тексту в `index.html`:
  додай пару `"український текст": "English text"` у словник `T`
  у `tools/make_en.py` і запусти `python3 tools/make_en.py`.
- Скрипт має вивести тільки `Cyrillic left: ['Українська']`
  (назва мови в перемикачі — так і задумано). `NOT FOUND` або інша
  кирилиця = щось не перекладено.
- Переклад — природна англійська, не дослівна.

## Дизайн

- Референси: Calma, NOIRÉ, Hotellia, Aurelia (шаблони Framer).
  Спокійний «бутиковий» стиль, багато повітря.
- Палітра нейтральна (теплий білий `#faf9f6`, графіт `#1f2224`).
  **Без зеленого й «хакі»** — власнику не подобається.
- Фото показуються **без кольорових фільтрів**. Градієнтів поверх фото
  не робити — лише рівне затемнення `--overlay`.
- Заголовки — Literata з одним **курсивним словом** (`<em>`).
- Мітки над заголовками: `01 · Дім`, `02 · Номери`… (нумерація секцій).
- Назва готелю латиницею: **GUK** (лого, великі слова в hero і футері).
